# B站直播间自动点赞 · 亲密度助手

一个 Tampermonkey / Violentmonkey 用户脚本（油猴插件），在 B 站直播间自动点赞，帮助你每天拿满「点赞」渠道的粉丝牌亲密度。

## 规则对照

| 规则 | 数值 |
| --- | --- |
| 每点赞次数 | 30 次 = +1 亲密度 |
| 每日点赞亲密度上限 | 10（即最多 300 赞/天） |
| 有效条件 | 仅在主播开播期间点赞有效 |
| 计算范围 | 按直播间（粉丝牌）单独统计 |

脚本默认每次运行点到 310 次（300 次有效点赞 + 10 次冗余）后自动停止，进度按房间记录在本地，次日自动清零。

## 安装

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（或 Violentmonkey）；
2. 打开 [bilibili-live-auto-like.user.js](./bilibili-live-auto-like.user.js)，油猴会弹出安装页，点击安装；
3. 登录 B 站，打开任意直播间（https://live.bilibili.com/*）。

也可以直接从 Greasy Fork 安装：[B站直播间自动点赞 · 亲密度助手](https://greasyfork.org/zh-CN/scripts/593888)

页面右下角会出现悬浮面板：显示今日点赞进度（`今日 X / 310 赞（+Y/10 亲密度）`），可点击「开始 / 停止」随时控制。

## 使用说明

- 默认进入开播中的直播间后 1.5 秒自动开始点赞；未开播时面板显示「等待开播」，开播后自动开始；
- 默认「快速」档：每次点赞间隔 0.6～1 秒随机，每连续点 30 次暂停 3～5 秒，约 6 分钟点满 310 次；
- 面板里有「速度」选择：慢速 / 标准 / 快速，随时切换、自动保存；
- 点击「停止」可随时暂停，再次点击「开始」继续；进度不会丢失；
- 点击面板右上角「—」可折叠成一个半透明圆形小按钮（显示今日点赞数），不再遮挡直播画面；点击圆钮重新展开；
- 面板和圆形按钮都可以直接拖动位置，位置会自动保存，下次打开直播间恢复；
- 油猴菜单里提供：开始/停止、清空今日计数、折叠/展开面板；
- 同一天点满 310 次后会自动停止并通知，不需要手动干预。

## 可调参数

脚本开头 `CONFIG` 中可修改：

```js
LIKES_PER_INTIMACY: 30,        // 每 N 赞 = +1 亲密度
DAILY_INTIMACY_CAP: 10,        // 每日亲密度上限（默认 10 → 300 赞）
REDUNDANT_LIKES: 10,           // 冗余点赞（默认 +10，防止个别点赞漏记）
BATCH_SIZE: 30,                // 每连续点赞 N 次后暂停
AUTO_START: true,              // 进直播间后是否自动开始
LIVE_CHECK_MS: 60000,          // 未开播时多久重新检测一次（毫秒）
```

速度档位在脚本顶部的 `SPEED_PRESETS` 中定义（间隔与批次暂停均可改）：

```js
slow:   { min: 1500, max: 2500, batchPause: [5000, 9000] },  // 慢速
normal: { min: 1000, max: 1600, batchPause: [4000, 7000] },  // 标准
fast:   { min: 600,  max: 1000, batchPause: [3000, 5000] },  // 快速（默认）
```

B 站网页端单次点赞间隔最低约 500ms，低于这个值会被直接拒绝或触发风控。

## 实现说明

- 脚本直接点击直播间页面原生点赞按钮，由 B 站页面自己上报点赞，不发起任何跨域请求；
- 房间号、开播状态读取页面自带的 `window.__NEPTUNE_IS_MY_WAIFU__`（即 `roomInitRes.data`），读不到时回退到 URL 解析；
- 每日计数存放在 Tampermonkey 本地存储（键 `biliAutoLike.daily.v1`），只存日期与各房间点赞数，不收集任何个人信息；
- 参考脚本 [bili-cat-butler.user.js](https://github.com/coni233/bili-cat-butler) 的存储/面板/菜单模式编写，但功能独立、更轻量。

## 注意事项

- 默认快速档已接近 B 站下限，若遇到点赞无效或被风控，请切换为「标准」或「慢速」；
- 如果页面改版导致点赞按钮选择器失效，面板会提示「未找到点赞按钮」，届时更新 `LIKE_SELECTORS` 即可；
- 本脚本仅用于个人粉丝牌亲密度挂机，请遵守 B 站社区规范，合理使用。
